# 来源质量分级

目标：自然用语和网络用语必须看来源质量。不同来源只能支持不同强度的规则。

## 1. 来源等级

### A: 官方 / 学术 / 大型语料库

可用于沉淀长期规则。

例：

- 国家语言资源监测与研究中心相关发布
- 商务印书馆“汉语盘点”
- BCC、CCL 等语料库
- LDC、论文、可追溯数据集

允许用途：

- 总结语言现象
- 记录年度词语
- 建立新鲜度策略
- 支持语体和句法规则

不允许用途：

- 直接把年度热词写进普通文案

### B: 平台实时数据 / 热搜聚合

可用于判断短期热度，但不能沉淀长期规则。

允许用途：

- 判断某词近期是否仍可见
- 给 `observedAt` 提供时间证据

限制：

- 需要记录平台
- 需要定期复查
- 不可单独支持 `autoUse: true`

### C: 媒体科普 / 教学博客

可用于理解用法，但不能作为新鲜度最终证据。

允许用途：

- 初筛网络词
- 记录解释和例句

限制：

- 默认 `needs-check`
- 不自动使用

### D: 百科 / 社区词典

可用于了解背景，但不能代表当前自然使用。

允许用途：

- 记录来源和梗背景

限制：

- 默认 `platform-bound` 或 `needs-check`
- 不自动使用

## 2. 规则强度

```text
A 类来源 -> 可支持长期结构规则
B 类来源 -> 只支持短期观察
C 类来源 -> 只支持解释，不支持自动使用
D 类来源 -> 只支持背景，不支持自动使用
```

## 3. 入库要求

每条网络词观察必须写：

- `term`
- `observedAt`
- `source`
- `sourceQuality`
- `platform`
- `status`
- `autoUse`
- `notes`

缺一项，不入库。

## 4. 自检

触发：准备把一个网络词写进文案或样例。

判断：如果来源不是 A 或 B，且没有 180 天内证据，就不能当“当前自然用语”。

改法：把词还原成普通中文动作或情绪；只把该词留在观察表里。
