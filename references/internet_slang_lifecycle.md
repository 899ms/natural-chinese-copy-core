# 网络用语生命周期

目标：网络词不能当“自然中文”的捷径。它有时效、平台和人群边界。

## 1. 当前来源

已记录来源：

- “汉语盘点2025”相关发布，年度新词、流行语、网络用语由国家语言资源监测与研究中心等机构发布。
- 2025 年度十大网络流行语相关报道提到语料来自网络媒体、专家意见和站点收录，语料规模超过 78 亿字符。
- BCC 语料库页面显示包含多领域语料，口语规模约 2.32 亿字，页面统计时间到 2026-05-21。

使用网络词前必须重新确认日期。年度榜单只说明某一年流行，不代表今天仍然自然。

结构化观察表见 `slang_observations_2026.jsonl`。观察表不是白名单，默认不自动使用。

## 2. 生命周期分级

- `emerging`: 最近 30 天内出现，热但不稳定。
- `current`: 最近 180 天内仍在高频使用。
- `mainstream`: 已进入大众表达，不依赖平台热度。
- `stale`: 曾经流行，现在容易显得过时。
- `ironic`: 主要用于反讽，误用会尴尬。
- `platform-bound`: 只在特定平台自然。

## 3. 使用规则

触发：文案里想用网络词、热梗、平台口头禅。

判断：

- 是否是用户要求的语体？
- 是否和平台匹配？
- 是否在最近 180 天仍常见？
- 是否会遮住事实？
- 是否让读者觉得装熟？

改法：

- 不确定新鲜度时不用。
- 不确定受众时不用。
- 如果只是为了显得口语化，改用普通短句。

## 4. 年度热词怎么用

年度热词不是推荐词库，只是观察材料。

可以学：

- 它怎么压缩情绪。
- 它适合什么关系距离。
- 它在句子里承担判断、吐槽、认同还是反讽。

不要做：

- 看到年度词就塞进文案。
- 把热词写进长期黑名单或长期白名单。
- 把平台梗用于正式说明。

## 5. 过时风险

高风险信号：

- 词本身来自某个平台热梗。
- 依赖短视频或弹幕语境。
- 用户不在该圈层。
- 已经被营销号滥用。

处理：

```text
网络词 -> 普通中文动作 / 情绪 / 判断
```

例：

```text
有点东西 -> 这里有一个具体点值得看
狠狠提升效率 -> 少掉重复解释和手动排查
情绪价值 -> 具体写它让用户少焦虑、少等待、少重复沟通
```

## 6. 入库要求

任何网络词进入 reference 前，必须记录：

- 词条
- 来源链接
- 观察日期
- 主要平台
- 使用人群
- 语用功能
- 新鲜度状态
- 是否允许自动使用

默认：不允许自动使用。除非用户指定平台语体，或 reference 已确认它是 mainstream。
